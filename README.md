# kish-karen-UI

آموزشگاه زبان کیش کارن و مدارس غیردولتی کارن با مدیریت دکتر مجتبی غلامیان
Kish Karen Language Academy Official Website & User Interface

## تکنولوژی‌های استفاده‌شده

- **Next.js 16 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Keen Slider**
- **Motion (Framer Motion)**
- **Radix UI & RTL Direction Provider**
- **Iconify**

## راه‌اندازی پروژه

```bash
pnpm install
pnpm dev
```

سپس مرورگر را باز کرده و به آدرس [http://localhost:3000](http://localhost:3000) مراجعه کنید.

## بیلد پروداکشن

```bash
pnpm build
pnpm start
```
